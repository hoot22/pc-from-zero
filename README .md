# 一、电脑基础
## （一）外设
### (1) 显示器
用于显示内容的屏幕。主要参数为：
1. 大小（单位：寸）
2. 分辨率（主流分为 720P、1080P/1K、2K、4K、8K）
3. 刷新率（单位：Hz），主流有 30Hz、60Hz、75Hz、144Hz、300Hz 等
4. 支持的色域范围
### (2) 键盘
一种输入设备。上有英文字母、标点符号、数字等按键。现在键盘上常带有背光、光效／音量调节旋钮等功能。主要参数为：
1. 响应速度
2. 按键数量
3. 重量
其连接方式分有线（USB）与无线（蓝牙、WiFi）。
### (3) 鼠标
一种输入设备。分左、中（滚轮）、右三键。现在的鼠标也会配一些侧边按键（例如前进、后退）。连接方式分有线（USB）与无线（蓝牙、WiFi）。主要参数为：
1. DPI／灵敏度
2. 重量（单位：g）
## （二）内设
### (1) CPU：
中央处理器，用于计算。主要参数：
1. 制程：2nm、3nm、5nm、10nm……
2. 基础频率（单位：GHz）
3. 核心数／线程数（单位：核／线程）
4. 缓存（单位：MB）
5. 功耗（单位：W）
6. 接口（插槽）：决定以后能不能只换 CPU 不换主板
### (2) GPU
图形处理器，用于渲染。主要参数：
1. 制程 
2. 基础频率 
3. 显存大小（单位：GB）
4. 显存带宽（单位：GB/s）
5. 显存位宽（单位：bit）
### (3) 内存（RAM）：
主要参数：
1. 容量（单位：GB），常见 8／16／32
2. 代际：DDR4／DDR5（插槽不同，不能混用）
3. 频率（单位：MT/s），常见 DDR4-3200、DDR5-6000
4. 时序（CL），同频率下越小越快
5. 通道数：单／双通道，双通道带宽翻倍（两条 8G 比一条 16G 快）
## （三）查询你的配置
你可以使用Windows自带的任务管理器查询，win+x点击`任务管理器`，打开后选择`性能`，即可看到你的配置。你也可以选择安装一些第三方工具箱查看。
## （四）操作系统
目前市面上主流的操作系统有`Windows`，`macOS`，`Linux`。本文在无特殊说明下仅讨论`Windows`环境下
### (1)文件系统
Windows以盘的形式划分硬盘，单块硬盘可划分单个或多个盘。盘符以英文字母命名，盘的名称可自定义（例：C盘、系统盘、工作盘）
1. 文件路径：每个文件在文件系统上的地址，例如：C:\123\123.txt
2. 文件扩展名：写在文件后的拓展名，用于表示该文件的格式，例如：.exe表示可执行文件，.txt表示文本文件，.py表示 Python 脚本。如果您发现您的文件后没有扩展名，则可能是被系统隐藏了，您可以在文件资源管理器上方的显示设置中打开显示。
3. 隐藏的项目：被系统隐藏的文件/文件夹，可在文件资源管理器的显示设置中打开“显示隐藏的项目”，一般而言，文件夹前带有“.”的，都是隐藏的项目
### （2）解压缩
压缩文件主要有`.zip`,`.7z`,`.rar`。解压时，您需要使用解压缩工具，在win10与win11中，都有自带的解压缩工具（win10的只能解压.zip格式的），因此，除非您的系统版本过老或格式不支持，否则，您一般是不需要下载第三方解压缩工具的。
